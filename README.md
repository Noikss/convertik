# 🤖 Session → TData Converter Bot

Telegram-бот для конвертации аккаунтов из формата `.session + .json` в `tdata`.

---

## 📁 Структура проекта

```
bot.py            # Основной файл бота
requirements.txt  # Зависимости
README.md         # Этот файл
.gitignore        # Исключения для Git
```

---

## 🚀 Деплой на Bothost

### 1. Загрузи файлы в Git-репозиторий
Залей `bot.py`, `requirements.txt`, `.gitignore` в репо.

### 2. Подключи репо на Bothost
В панели управления → подключи свой GitHub репозиторий.

### 3. Переменные окружения
В панели Bothost добавь переменные окружения:

| Переменная   | Значение                          |
|--------------|-----------------------------------|
| BOT_TOKEN    | токен от BotFather                |
| API_ID       | твой api_id с my.telegram.org     |
| API_HASH     | твой api_hash                     |
| PROXY_HOST   | IP прокси                         |
| PROXY_PORT   | порт прокси                       |
| PROXY_USER   | логин прокси                      |
| PROXY_PASS   | пароль прокси                     |

### 4. База данных
База SQLite создаётся автоматически в папке `/app/data/bot.db` при первом запуске.
Папка `data` на Bothost сохраняется между перезапусками.

---

## 📦 Как пользоваться ботом

1. Упакуй аккаунты в ZIP:
   ```
   archive.zip
   ├── account1.session
   ├── account1.json
   ├── account2.session
   └── account2.json
   ```

2. Отправь архив боту

3. Получи `tdata_result.zip` с готовыми папками tdata
